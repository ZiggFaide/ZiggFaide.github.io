# riusn brand

Mark: a pixel-art lowercase "r" on a coral square with notched (pixel-rounded) corners, drawn on a 10x10 grid.
Always scale it in whole-pixel steps (10, 20, 30... px) so the cells stay sharp.

Colours
- Coral (accent)   #ff6b57
- Navy (background) #141830
- Navy raised      #1c2142
- Lines            #2f3560
- Shadow           #0a0c1d  (hard drop shadows, never blurred)
- Cream (text)     #f6ecd6
- Muted            #9da0bf

Type
- Pixelify Sans: headings, wordmark, buttons
- Silkscreen: small uppercase labels
- IBM Plex Sans: body text
- IBM Plex Mono: discount codes and tables
(All free under the SIL Open Font Licence; copies in ../fonts.)

Files
- mark.svg / mark-512.png     logo mark
- mark-mono.svg               just the "r", one colour
- store-logo-square.png       full-bleed square for store/profile pictures (survives circle crops)
- logo-wordmark.png           mark + name, for banners
- og.png                      preview image when the site link is shared
- favicon-32.png, apple-touch-icon.png, ../favicon.svg   browser and phone icons

Rules: use coral sparingly (one main thing per screen). Pixel details come from hard
edges and offset shadows, not glows, gradients or emoji.
