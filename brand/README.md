# ZiggFaide brand

Mark: a double zigzag "Z" cut out of an orange square.

Colours
- Orange (accent)  #e4572e
- Ink (background) #14120f
- Paper (text)     #efe7d6
- Muted            #9d9483

Type
- Fraunces: headings and wordmark
- IBM Plex Mono: small uppercase labels
- IBM Plex Sans: body text
(All free under the SIL Open Font Licence; copies in ../fonts.)

Files
- mark.svg / mark-512.png     logo mark, rounded
- store-logo-square.png      square mark for store/profile pictures (Lemon Squeezy, YouTube, etc.)
- logo-wordmark.png          mark + name, for banners
- og.png                     preview image when the site link is shared
- favicon-32.png, apple-touch-icon.png, ../favicon.svg   browser and phone icons

Rules: use orange sparingly (one main thing per screen); no glows, gradients or emoji.
